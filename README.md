# About a project
Приложение напоминает пользовательский форум на котором пользователи могут оставлять комментарии для этого нужно  имя пользователя e-mail и сам текст сообщения. 
в тексте самого комментария разрешается выделять всё жирным шрифтом(нажать на <strong>) ,курсивом (нажать на <i>),  добавлять ссылки (нажать на <a>), также использовать тег <code> для вставки фрагментов кода. Опционально можно добавлять файл к комментарию и адрес сайта самого пользователя. Можно отвечать на комментарии других пользователей. Для этого под коментарием нужно нажать на кнопку ответить. Также можно отвечать на сами ответы других пользователей. Для этого под коментарием нужно нажать на кнопку ответить под другим ответом.  Можно сортировать комментарии по имени пользователя почте или дате создания комментария. Для этого необходимо вверху стобца нажать на username, email или дата. После клика по интересующему нас столбцу (например дата) появится стрелочка , если она направлена вниз - значит сортировка по убыванию (т.е начиная с последнего добавленого коментария). Если стрелка направлена вверх - с первого дабавленого коментрария. username, email сортировка по алфавиту. Если стрелка направлена вверх - А-Я, вниз - Я-А.  На странице доступно по 25 комментариев, для того чтобы переключиться на следующую или предыдущую страницу прокрутите до самого низу приложения и там будут доступны кнопки для перехода на сдедущую или предыдущую страницу. 

## Environmental requirements
Проект написан на ASP.NET Core 10 версии, язык програмированния C#, angular 21 и базой данных МS SQL server 2022.
 На компютере для локального запуска проекта должно быть установлено:
1. visual studio 2026
2. MS SQL Server 2022 или более поздней версии. 
3. node js LTE 24 
4. Anular CLI 21.1

## Development local server
Скачиваем проект локально bash "git clone https://github.com/radik87/CommentsDzen.git".
Открываем папку CommentsDzen и запускаем Comments.slnx, перейдя в visual studio открываем вкладку view/other windows/package manager console.
Поскольку наш проект создан подходом code first для того чтоб локально создать базу данных пишем  add-migration "Init", затем update-database.
Нажимаем f5. Откроеться https://localhost:44304/ page not found, все ок работают API.
Заходим в папку comments-frontend. Пишем команду bash  "npm i". Далее команду bash "ng serve". Откроеться порт https://localhost:4200/. 
Переходим в браузере по адресу https://localhost:4200 и пробуем добавлять коментарии и файлы к ним.
Файл SchemaCommentDb.sql 100% правильно написан т.к. по скрипту с этого файла на хостинге azure создавались таблицы в Б.Д.

## Docker container
Разархивировать dockerProj.zip зайти в папку и выполнить команду bash "docker compose up --build"
